# PairCheck · 双表核对

在浏览器本地按唯一编号核对两份 CSV 的金额，找出缺失记录与金额差异，导出可复核的异常明细。适合核对订单导出、收款导出和其他采用相同编号体系的数据。

**免费工具 · 本地处理 · 无需注册 · MIT 许可**

[下载免费离线包](https://github.com/AkiraNyx/paircheck/releases/download/v0.1.0/paircheck-offline.zip) · [查看合成样例](docs/samples/orders.csv) · [使用与许可](docs/OFFLINE-README.txt)

## 能做什么

- 按编号匹配，行顺序不同也能比较；左右表的列名可以不同。
- 使用十进制定点整数运算，支持最多 6 位小数，保留编号前导零。
- 将一致、金额不同、仅左表、仅右表分开列出，并保留原表记录号。
- 遇到重复编号、空编号、无效金额或坏 CSV 时停止核对。
- CSV 内容只在浏览器内存中处理，不上传，不写入本地存储。

## 直接使用

下载离线包并解压，用现代浏览器打开 `index.html`。点击“载入合成样例”，预期看到 **2 条一致、3 条异常**，其中编号 `0002` 的金额差额为 `3.00`。

处理自己的文件时，选择两份 CSV，分别指定编号列和金额列，再点击核对。工具最多预览 100 条，导出包含全部异常。

也可下载或克隆仓库，直接打开 `docs/index.html`；不需要 Node.js、Python 或服务器来使用网页工具。

## 使用边界

每份 CSV 上限 **5 MB / 20,000 条记录**，逗号分隔、首行为表头。支持 UTF-8 和 GB18030/GBK；Excel 文件请先另存为 CSV。金额不接受千分位、货币符号或科学计数法。

请先确认相同币种、业务范围、退款及手续费口径。工具不会自行合并重复编号、判断哪张表正确或认定平台结算结果。比较结果不能替代财务或税务结论。
