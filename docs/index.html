几个常见问题

文件会被上传或保存吗？

核对代码只在浏览器内存中读取 CSV，不向服务端发送内容，也不写入本地存储。清空或关闭页面会移除当前数据；你主动导出的文件会保留在下载目录。在线页面本身由托管方提供，离线包可断网使用。

为什么不直接支持 Excel？

第一版只处理逗号分隔 CSV，让过程简单、可检查。请在 Excel 中另存为“CSV UTF-8”；含前导零的编号应在原始导出中保持文本，工具不能恢复已被 Excel 丢掉的零。

结果能作为财务结论吗？

这是所选编号与金额字段的确定性比较。核对前请自行确认币种、订单范围、时区、退款、税费与结算口径；平台结算认定仍需结合业务规则复核。
